#SOME BASIC LINUX COMMANDS USED EVERYDAY#
- `pwd:` To determine the present Working Directory.
- `ls:` To list all the files.
- `cd:` To change the Directory.
- `ls -l:` To display the details of the files.
- `man:` To Display the details/Workings of some Command.

#Files and Folder Management#

- `mkdir:` To create a Folder.
- `touch:` To create a File.
- `cp:` To Copy some File/Folder into another File/Folder.
- `cp -r:` To Copy a Directory into another Directory.
- `mv:` To Move/Rename a File or a Folder.
- `rm:` To remove a File.
- `rm -r:` To remove a Folder.
- `ip addr:` To determine the ip address of the current instance.
- `ping:` To test if a Networking Website/Device is reachable.
- `ps:` To determine all the processes active/running on the system.
- `ps -a:` To get the details of all the running processes on the system.
- `ps aux | grep opr:` To determine if the "opr" is withing the list of running/active processes or not.
- `top:` To Display all the Running/Working Processes along with their Details.
- `free:` To display how much Memory is free.
