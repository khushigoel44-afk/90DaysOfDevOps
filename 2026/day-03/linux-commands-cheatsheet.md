**SOME BASIC LINUX COMMANDS USED EVERYDAY**
-1> pwd: To determine the present Working Directory.
-2> ls: To list all the files.
-3> cd: To change the Directory.
-4> ls -l: To display the details of the files.
-5> man: To Display the details/Workings of some Command.

**Files and Folder Management**

-6> mkdir: To create a Folder.
-7> touch: To create a File.
-8> cp: To Copy some File/Folder into another File/Folder.
-9> cp -r: To Copy a Directory into another Directory.
-10> mv: To Move/Rename a File or a Folder.
-11> rm: To remove a File.
-12> rm -r: To remove a Folder.
-13> ip addr: To determine the ip address of the current instance.
-14> ping: To test if a Networking Website/Device is reachable.
-15> ps: To determine all the processes active/running on the system.
-16> ps -a: To get the details of all the running processes on the system.
-17> ps aux | grep opr: To determine if the "opr" is withing the list of running/active processes or not.
-18> top: To Display all the Running/Working Processes along with their Details.
-19> free: To display how much Memory is free.
